### 🚀 Custom Native SDK Ecosystem (Free vs. Pro)

#### 1. Public Free Open Source Packages (Published on npm)
* **[react-native-nitro-fused-location](https://www.npmjs.com/package/react-native-nitro-fused-location)** – Lightweight offline GPS tracking module built using Nitro Modules for zero-bridge overhead native performance. Features Fire OS and GMS-less device compatibility via native `LocationManager`, zero Google dependencies (pure AOSP APIs), real-time distance/speed tracking, and core APIs (`getCurrentLocation`, `watchPosition`, `setGeofence`).
* **[react-native-nitro-open-map](https://www.npmjs.com/package/react-native-nitro-open-map)** – High-performance native map component built with Nitro Modules and MapLibre Native. Provides fast native Android and iOS map rendering with zero bridge overhead, standard markers, custom icons, polygon/polyline overlays, user location tracking integration, and camera/zoom controls.
